Desktops&gt;&gt; Run Baby Run

May 7, 2012 Bryn Musselwhite

You may have noticed that we like how well-observed Rob Richardson’s Toyota KP30 is.

From the Compomotive split rims to the TRD harnesses, it’s a little bit of Japan in the leafy suburbs of England.

It’s been mistaken for everything from a Fiat Coupé to a Mk2 Escort; we’re Speedhunters and we know what it is.

A 5K, rev-happy, earth-bound smile machine.

So take a closer look…

…and if you see it out and about, Rob and his infectious attitude won’t be far away…
